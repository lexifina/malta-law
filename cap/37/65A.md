# 65A. Application of Criminal Code.
(1) Every offence provided for in this Ordinance shall, to all legal intents and purposes, be deemed a crime within the meaning of the Criminal Code and, subject to the special provisions of this Ordinance, be dealt with as such.
(2) The provisions of the Criminal Code relating to the punishment described in that Code as a fine (multa) shall apply to the pecuniary penalties laid down in this Ordinance.
