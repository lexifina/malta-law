## SCHEDULE IV
# schedule-iv
Based on Annex IV of Directive 1995/13/EC
ENERGY EFFICIENCY CLASS
The energy efficiency class of an appliance shall be defined in accordance with the following tables:
Table 1 - Air vented driers
Energy efficiency class Energy consumption 'C' in kWh per kg
of load using test procedures of the harmonized standards referred to in
regulation 4(6) with 'dry cotton cycle'
A C < 0.51
B 0.51 < C < 59
C 0.59 < C < 0.67
D 0.67 < C < 0.75
E 0.75 < C < 0.83
F 0.83 < C < 0.91
G 0.91 < C
Table 2 - Condensing driers
Energy efficiency class Energy consumption 'C' in kWh per kg
of load using test procedures of the harmonized standards referred to in
regulation 4(6) with 'dry cotton cycle'
A C < 0.55
B 0.51 < C < 64
C 0.64 < C < 0.73
D 0.73 < C < 0.82
E 0.82 < C < 0.91
F 0.91 < C < 1.00
G 1.00 < C
Determined according to Schedule I, note V.
