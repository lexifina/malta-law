# 27. Duplicate passed test results.
(1) If a passed test result has been lost or defaced, an application for the issue of a duplicate of the original passed test result may be made to the operator where the test has been carried out.
(2) The operator to whom the application is made shall issue a duplicate passed test result only when sufficient particulars of the successful test of the vehicle are traced; and such passed test result shall be marked "Duplicate", and shall have the same effect as the original passed test result:
Provided that no action to trace the passed test result shall be taken if the original passed test result was issued more than twenty-four months previously, or if the applicant does not furnish with his application the approximate date when the original was issued and any other information which could help to trace the document.
- Amended by: L.N. 43 of 2008.
