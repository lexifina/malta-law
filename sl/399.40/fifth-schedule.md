## Applicability of Fifth Schedule.

## Minimum technical parameters.
# fifth-schedule
(Regulation 3)
General Authorisation for Radiocommunications Apparatus
intended to be used for Inductive Applications
1. This Schedule shall apply to any person installing or using
short-range radiocommunications apparatus intended to be used for inductive applications or any apparatus intended to be used as a component part of that apparatus.
2. In this Schedule "Short-range radiocommunications
apparatus intended to be used for inductive applications" means apparatus that uses magnetic fields with inductive loop systems for near field communications.
3. The minimum technical parameters of short-range
radiocommunications apparatus intended to be used for inductive applications, shall be those specified in the Annex to this Schedule.
